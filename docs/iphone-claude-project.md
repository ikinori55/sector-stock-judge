# iPhoneのClaudeだけでセクター分析する（プロジェクト設定）

PCを一切使わず、**iPhoneのClaudeアプリで「分析して」と言うだけ**で
日米セクターの短期／中期／長期の5段階評価が表示されるようにする設定。

## 仕組み

```
GitHub Actions（平日16:30 JST に自動実行 / iPhoneから手動実行も可）
  → クラウドでデータ取得・判定 → site/mobile.json を公開
GitHub Pages が公開URLで配信
iPhoneのClaudeプロジェクト → 「分析して」→ mobile.json をfetch → 5段階を表で表示
```

- iPhone側は**公開JSONを読むだけ**。データ生成はクラウドで自走するのでPC不要。
- ローカルのフル分析（スクリプト＋エージェント）はそのまま残る（PCで使うとき用）。

## 公開されるデータURL

初回セットアップ（`deploy-github-pages.md`）が済むと、以下が公開される。
`<user>` と `<repo>` は自分のものに置き換える。

- 軽量版（iPhone用・これを使う）: `https://<user>.github.io/<repo>/mobile.json`
- フルデータ: `https://<user>.github.io/<repo>/latest.json`
- 人が見るダッシュボード: `https://<user>.github.io/<repo>/`

`mobile.json` の中身（各セクター）:
`name / short（短期=1日+1週）/ mid（中期=1ヶ月）/ long（長期=3ヶ月）/ overall（総合）/ momentum（勢い）`
short/mid/long は **強気・やや強気・中立・やや弱気・弱気** の5段階（同一市場内のセクター相対ランクの五分位）。

## iPhoneでの設定手順（1回だけ）

1. iPhoneの **Claudeアプリ → プロジェクト → 新規プロジェクト**（例:「セクター分析」）を作る。
2. プロジェクトの **カスタム指示（Instructions）** に下の指示文を貼り付ける。
   URL の `<user>/<repo>` は自分のものに直す。
3. 以降は、そのプロジェクトのチャットで **「分析して」** と送るだけ。

## 貼り付けるカスタム指示（テンプレート）

```
あなたは日米株式のセクター強弱レポーターです。

「分析して」「セクター分析」などと言われたら、次のURLの最新JSONを取得して回答してください:
https://<user>.github.io/<repo>/mobile.json

回答の作り方:
1. まず generated_at（生成時刻）と、各市場の as_of（データ基準日）を1行で示す。
2. 日本株(jp) と 米国株(us) それぞれについて、セクター一覧を表で出す。
   列は「セクター / 短期 / 中期 / 長期 / 勢い」。
   - 短期=short, 中期=mid, 長期=long（各セクターの値をそのまま使う。強気〜弱気の5段階）。
   - 勢い=momentum。
   - overall（総合）が「強気」→「弱気」の順に並べ替えて表示する。
3. 表の後に、短期で「強気／やや強気」が多いセクターと「弱気／やや弱気」が多いセクターを
   数行で要約する（例: 短期は◯◯・◯◯が強く、△△・△△が弱い）。
4. 5段階は同一市場内でのセクター相対ランク（五分位）による相対評価であることを一言添える。
5. 投資勧誘ではなく情報提供である旨を最後に1行入れる。

JSONが取得できない場合は、URLが正しいか・GitHub Pagesが公開済みかを確認するよう促す。
数値やセクター名を勝手に創作しない。取得したJSONの内容だけで答える。
```

## 最新データにその場で更新したいとき（任意）

定期実行を待たずに今すぐ更新したい場合は、次のどちらか（どちらもiPhoneで可能）:

- **GitHubアプリ / Safari** で リポジトリ → Actions → 「Build sector dashboard」→ Run workflow。
  数分後に mobile.json が更新される。
- **ClaudeアプリにGitHubコネクタを接続**しておけば、Claudeに
  「セクターのワークフローを実行して最新化してから分析して」と頼める
  （コネクタ設定が必要）。

通常は平日16:30 JSTの自動更新に任せてよい。
